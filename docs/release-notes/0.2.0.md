# Binders 0.2.0

To-dos and calendar events by voice, automations, an MCP server, Settings you can find your way around, and a fix for typing lag.

- Say it, and it's on the list. In Command Mode (hold fn ⌃), "add to-do call Sam tomorrow" or "remind me to send the deck by Friday" puts a to-do on your board, with the time split off as its due date and a reminder if you have those on.
- Say it, and it's on the calendar. "Add it to my calendar" takes what you just dictated, or the selected text, and makes an event of it; "add lunch with Sam tomorrow at noon to my calendar" says it outright. Times as people say them work: "Monday, eleven a.m.", "half past ten", "at three". Binders asks for calendar access the first time.
- Automations. Settings → Automations holds rules: when you say a phrase in Command Mode, or when a dictation lands, a to-do is added, a promise is noted, meeting notes are ready or writing is captured, run a Shortcut, open a URL, run a script or call a web hook, with placeholders for the text, title, time and more. Rules live in a JSON file you can read and share.
- Links. Anything that can open a link can drive Binders: binders://todo, binders://calendar, binders://ask, binders://dictate, binders://capture, binders://meeting and binders://open.
- An MCP server. Claude Code, Claude Desktop and other AI tools can search and ask your knowledge base through the Model Context Protocol, and add to it: notes, binders, meetings from elsewhere, to-dos and calendar events. On this Mac only: Binders --mcp. Settings → Automations has the configuration to copy.
- Settings is now ten short pages, General to Privacy, with a list down the left to click through, instead of one long scroll.
- Keystrokes no longer wait for Binders. The keyboard listener now runs on its own thread, so nothing the app does can delay what you type in other apps.
- Settings stopped re-rendering itself every two seconds, and no longer asks macOS about "Launch at login" on every render. Once you had opened Settings, this kept running in the background, even with the window closed, and each pass held up your typing for a moment.
- Closing the Binders window now releases its views instead of keeping them alive unseen.
