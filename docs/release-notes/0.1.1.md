# Binders 0.1.1

Fixes typing lag across the whole Mac.

- Keystrokes no longer wait for Binders. The keyboard listener now runs on its own thread, so nothing the app does can delay what you type in other apps.
- Settings stopped re-rendering itself every two seconds, and no longer asks macOS about "Launch at login" on every render. Once you had opened Settings, this kept running in the background, even with the window closed, and each pass held up your typing for a moment.
- Closing the Binders window now releases its views instead of keeping them alive unseen.
