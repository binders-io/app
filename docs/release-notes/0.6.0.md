# Binders 0.6.0

The model can run inside Binders, notes became a proper editor, and the crash after lots of edits is gone.

- Built-in models. Settings → AI → Built in (MLX) runs the language model inside Binders on Apple silicon, with Apple's MLX: nothing else to install, for Macs where Ollama isn't allowed. Pick Gemma 4 or Qwen 3.5 by your Mac's memory and Binders downloads it, from Hugging Face or your company's mirror of it, or use a model folder IT provides. Search by meaning runs built in too. New installs on Apple silicon start here; Macs already using Ollama keep it. On the same Gemma 4 26B, cleanup came out a little quicker than through Ollama (1.44 s against 1.53 s) with a fifth less memory, and the model no longer has to make room for the search model.
- Fixed: Undo could crash Binders after a card's description or another editor had closed. Each editor now has its own Undo.
- Typing stays quick in long notes and big libraries: a keystroke took over 100 ms in a busy Notes page and now takes about 3.
- Pictures, videos and files in notes. Drop them in, paste a screenshot, or add them from the toolbar; they're kept beside the note and travel with shared notes. Resize a picture from its menu; a video plays in Quick Look.
- Type / for anything a note can hold: headings, checklists, tables, code, a divider, a picture, a link, the date.
- Tables show as a grid; Tab moves from cell to cell. Code is coloured. Web addresses are links.
- ⌘F finds and ⌥⌘F replaces. Typing * or [ over a selection wraps it. ⌥⌘↑ and ⌥⌘↓ move lines. A web page or a document pasted in comes in as Markdown (⌥⇧⌘V for plain words).
- Delete a note with ⌫, ⌦ or two fingers to the left, and Undo brings it back with its history.
- Pop a note out into a window that stays in front of everything, or fold it into a coloured bubble on the edge of the screen. They come back after a restart.
- ⌘N makes a note and puts the cursor in it; ⌥⌘N makes one in its own window.
- ⌘= and ⌘- make the words in notes bigger or smaller; ⌘0 puts them back.
- Every menu command's shortcut can be changed in Settings → Shortcuts.
- The digest beside a note can be dragged wider, narrower or out of the way.
- Writing capture works in any app: Settings → Writing capture → Add an App picks from what's running.
