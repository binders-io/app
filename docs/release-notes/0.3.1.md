# Binders 0.3.1

Notes that look like documents, to-dos that stay ticked, and a few things you asked for.

- Notes are shown rendered. The Markdown (#, **, [ ], a link's address) disappears, list dashes become bullets and checklists read as checkboxes; the markup comes back, faintly, only on the line you're editing. The # button in the toolbar keeps it visible everywhere, if you'd rather see it. ⌘-click a link to open it.
- Delete or Backspace on a note in the list deletes it. It asks once, Return confirms, and the next note is selected, so you can clear several in a row. Right-click → Delete… works too.
- The digest has a Copy button, and Copy Digest on right-click, that copies it as Markdown.
- A note that starts with "# Title" is listed as "Title".
- To-dos you tick in a note's digest or a meeting's notes stay ticked when the digest or the notes are rewritten.
- AI tools see your whole board over MCP: list_todos now includes the checklist items in meeting notes, notes and digests, and set_todo_status ticks them where they live.
