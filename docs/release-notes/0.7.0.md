# Binders 0.7.0

What you ask AI tools in the terminal is kept, the knowledge base can be corrected, and a freeze in the notes editor is gone.

- Prompts you send AI agents in the terminal are kept with your writing, in the binder that's open: Claude Code, Codex, Gemini CLI, Qwen Code, Copilot CLI and OpenCode, read from each tool's own record while writing capture is on. Terminal screens are still never read, and neither are shell commands or pasted text. Settings → Writing capture → In the terminal turns each tool off. Other tools can hand prompts over from a hook (`Binders --capture-prompt`), or be described in `agent-harnesses.json` so Binders reads them like the rest; docs/CAPTURE.md has the details.
- Correcting the knowledge base. AI tools connected over MCP can now fix what Binders has wrong: `correct_knowledge` takes the wrong statement and what's right. A note that says it is fixed in place, with its earlier version in its history; meetings and dictations stay as they were said. The correction is kept as a note tagged #correction, search marks passages that still say the wrong thing, and Ask answers from the correction. `update_note` changes a note: one passage, or the whole text.
- Fixed: Binders could freeze for several seconds after adding a code block. The block's lines were left selected, and with the pointer over a selection macOS looked up every share extension while Binders waited; once, that took 17 seconds. The editor no longer offers a share button over selected text (Share is still in the right-click menu).
- Fixed: ⌘N made a note without putting the cursor in it, and with the window closed your typing could rename the binder instead. The binder's name is now edited by clicking it or with Rename….
- The code block button on an empty checklist item turns the item into the block, and ``` typed in a list item starts a code block instead of putting checkboxes on its lines.
- With Show Markdown on, tables stay plain Markdown instead of drawing a grid that can't line up.
- Settings → MCP lists the tools as Reads, Adds and Changes, and each tool tells the AI app whether it only reads, so the app can let lookups through and ask before anything changes.
