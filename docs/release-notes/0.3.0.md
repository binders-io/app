# Binders 0.3.0

Notes that format as you type, shortcuts you can set to anything, and a fix for Binders not opening.

- Binders opens again when an AI tool is connected to it. Claude Code, Claude Desktop and other tools start `Binders --mcp` in the background, and Binders mistook that for a second copy of itself and quit as soon as it launched. It now tells the two apart.
- Notes, the scratchpad and meeting notes format as you type: headings, bold, italic, strikethrough, inline code, code blocks, links, quotes, and bullet and numbered lists. They are still plain Markdown underneath, so nothing about your existing notes changes except how they look.
- Checklists. Start a line with "- [ ]" or press ⌘⇧L and it becomes a checkbox you can click to tick.
- Lists carry on by themselves: Return starts the next item, Return on an empty item ends the list, and Tab and ⇧Tab indent.
- A toolbar above every note, and the usual keys: ⌘B, ⌘I, ⌘E for code, ⌘K for a link, ⌘⌥C for a code block, ⌘⌥1 to ⌘⌥3 for headings.
- Setting a shortcut records exactly what you press. Pressing a shortcut that's already in use no longer runs it; it's recorded, and Binders tells you where it's used and offers to move it.
- A shortcut can be a modifier tapped twice. Click the field and tap ⌥ twice, and double-tapping ⌥ anywhere opens the scratchpad (or whatever you gave it).
- fn works in combinations such as fn W, the field shows the keys as you hold them, and Esc cancels.
